# Set targets

Apply the included [trade-context](../trade-context/SKILL.md) prerequisite. Use the confirmed pattern and resolved symbol/side tradebook together with relevant preparation or attached position guidance.

Prefer targets in the position's attached guidance, then clearly distinguish suggestions from unactivated preparation rules. Return the next relevant target first, respecting the trader's sequence and the position's known management state.

Keep exact levels, conditions and allocations from the plan. Do not invent reward multiples, price levels, percentages or exit sizes. Preserve whether an allocation is based on initial or remaining shares; ask briefly if the basis is missing. A broker acknowledgement does not prove a fill.

For a live question, give the next target in a few words; give multiple targets only when requested or needed to answer. If no target is evidenced, say "Target not defined" or ask one essential question. Expand for research or an explicit request for reasoning.

Chart snapshots and stale observations cannot establish a live target hit. Advice does not submit or approve an exit.
