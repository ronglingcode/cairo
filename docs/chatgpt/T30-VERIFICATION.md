# T30 — Cairo domain tools

The self-contained plugin replaces the runtime coding tool catalog with six Cairo reads/proposals. Backend checks scope each call to Cairo's owned workspace. Its private capability is distinct from the renderer command capability. Outputs retain source times, missing coverage, snapshot-only chart labels, and bounded collections.

Note proposals carry the saved revision, session, and five-minute expiry; they do not save notes or change attachments. Guidance activation and exact exit staging report unavailable until their later tasks. Opening, increasing, and reversing requests are rejected. No credentials are included in tool context.

Checks: 49 tests passed, TypeScript passed, and production build passed. The actual pinned Windows runtime loaded the bundled plugin through a local fake-provider request and exposed exactly six Cairo tools. OpenCode loads the catalog lazily on the first model request. No paid inference or broker mutation was sent. Existing nonfatal Rollup option warnings remain.
