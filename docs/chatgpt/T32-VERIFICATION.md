# T32 — Streaming trading copilot

The main process owns one OpenCode session and event subscription. Actual `session.text.delta` events feed streamed text; bounded session snapshots recover messages and tool status. Cancel uses `session.interrupt` with no resume. Reconnect disposes the old subscription, fetches current context, and reuses the session. A new app instance finds its marked session in the owned workspace. Uncertain prompt delivery is displayed, blocked pending inspection, and never automatically resent. Command IDs deduplicate identical payloads and reject changed reuse.

The renderer has a real composer, streamed conversation, tool states, cancel, reconnect and error display. It receives no runtime password or provider key. Default fake mode uses a local fixture provider through real OpenCode and clearly labels demo output. Optional `provider: "openai"` uses the configured model ID and `CAIRO_OPENAI_API_KEY`; the runtime config retains only the environment reference. Key substitution and bearer authentication were verified with a synthetic key against loopback, not with a real provider. See [official authentication guidance](https://developers.openai.com/api/reference/overview).

Checks: 54 tests, TypeScript and production build passed. Real pinned Windows runtime tests verified streaming before completion, cancellation, restart, recovered history, one subscription and no resends. Browser inspection saved temporary fixture notes, loaded 60 synthetic one-minute bars, sent a fake-model chat and reloaded to recover both notes and history. Missing broker setup did not block preparation/chat. No paid inference, real credentials or orders were used. Packaging remains T48; existing build warnings remain.

Run `npm run dev` for the Electron application. Its `config.json` is under Electron user data and appears in the setup message. The default fake model is a demonstration, not trading analysis. Set `provider` to `openai`, `model` to the model ID you want, and the key in the launch environment for real discussion, then restart the app. Set `CAIRO_MASSIVE_API_KEY` to load actual chart snapshots. Broker setup is independent of this milestone.

`npm run build` then `npm run preview:fake` runs the browser demonstration with disposable storage, synthetic chart data and the real OpenCode runtime. Stop it with Ctrl+C; it removes its temporary files. It does not claim live connectivity or a packaged-app check.
