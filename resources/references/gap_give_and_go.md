# Gap Give and Go

This tradebook is when there's something missing from [gap and go](./gap_and_go.md). But only a certain set of things can be allowed to be missing to be gap give and go. And it still need to have all the other things for gap and go. 

## Compromise 1: Too Far Above Key Level
The ideal gap and go is gap up near above a key level or consolidation range. But if the open price too far above it, it would be a better setup if it can pull back deeper to get closer to the key level.

## Compromise 2: Stopped Out After Gap And Go
It's a valid gap and go setup, after we take the gap and go setup, it stopped out. Later it formed a new pattern that's still above the key level. 


## Stock Selection
Same stock selection as [gap and go](./gap_and_go.md). It needs to have everything from gap and go with the exception that the gap doesn't have to **near** above a key level. It can be far above the key level.

So the same for
* Uptrend from Higher Timeframe
* Consolidation Before the Gap
* Light Resistance Above
* News-to-Open Path

## Key Level Selection Priority
Same as [gap and go](./gap_and_go.md)

## Bookmap Entry Patterns
* [Bid Reappear](./bookmap_patterns/bid_reappear.md)
* [Bid Step Up](./bookmap_patterns/bid_step_up.md)

The entry still need to be above the key level, but it's ok to be below vwap or above vwap

## Stop Loss
Stop loss is low of the day, if that's breached, we are done for the day for this stock for the long direction.

## Trade Management
Follow the [3-tier trade management](./shared/3-tier-live-trade-management.md)

### Core Tier
The most common core tier target is back to the intra day high. 
The `Reversal / Invalidation Signal` is the same as gap and go. But for gap give and go, we usually need to be more patient. So don't move stop loss, keep it at low of the day.

### Runner Tier
Still the same as runner tier logic from gap and go. And the most common trigger condition is the breakout of intra day high. If it can breakout high of day and hold, we can extend to a higher target.
